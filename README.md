## Portfolio Projects
 
### [cyberark-vault-architecture-theory](https://github.com/jossywayne23-bit/PAM-Fundamentals-CyberArk-Architecture)
Architecture reference documenting the CyberArk Vault's role in a PAM deployment — network isolation model, component communication design (PVWA/CPM/PSM), Safe-based access segregation, and Disaster Recovery Vault design.
 
**Key areas covered:** Vault isolation architecture, single-firewall-exception communication model, Safe-based access segregation, DR Vault failover design.
 
---
 
### [hashicorp-vault-pam-lab](https://github.com/jossywayne23-bit/hashicorp-vault)
Enterprise PAM concepts demonstrated using HashiCorp Vault, with explicit architectural parallel mapping to CyberArk Privilege Cloud — credential vaulting, policy-based access control, dynamic secret rotation, and audit logging.
 
**Key areas covered:** Credential vaulting, dynamic secrets with TTL rotation, policy-based access control, audit logging, CyberArk architectural parallels.
 
---
 
### [entra-id-okta-sso-federation](https://github.com/jossywayne23-bit/Microsoft-Entra-ID-Okta-SAML-2.0-SSO-Integration)
Bidirectional SAML 2.0 federation lab — Microsoft Entra ID as Identity Provider with Okta as Service Provider. Includes live SAML assertion capture and element-by-element validation.
 
**Key areas covered:** SAML 2.0 federation, metadata exchange, assertion validation, cross-platform SSO.
 
---
 
### [entra-id-rbac-design](https://github.com/jossywayne23-bit/rbac_permission_matrix)
Role-based access control model built across Microsoft Entra ID and AWS IAM, mapping job functions to permissions with a documented least-privilege matrix built before any platform configuration.
 
**Key areas covered:** RBAC design, permission mapping, least-privilege enforcement, cross-platform access modeling.
 
---
 
### [entra-id-conditional-access-mfa](https://github.com/jossywayne23-bit/Conditional-Access-Configuration---Entra-ID)
Conditional Access and MFA enforcement lab in Microsoft Entra ID, including phishing-resistant authentication policy design and blocked-login validation testing against a deliberately non-compliant account.
 
**Key areas covered:** Conditional Access policy design, MFA enforcement, risk-based access, blocked-flow validation testing.
 
---
 
### [user-lifecycle-jml-management](https://github.com/jossywayne23-bit/okta-jml-lifecycle)
End-to-end Joiner-Mover-Leaver lifecycle automation across Microsoft Entra ID and Okta, covering provisioning, role changes, and deprovisioning with audit trail documentation.
 
**Key areas covered:** Identity lifecycle management, provisioning/deprovisioning, access certification, audit documentation.
 
---
 
### [identity-monitoring-anomaly-detection](https://github.com/jossywayne23-bit/identity-monitoring-anomaly-detection)
Identity log analysis lab using sign-in and audit log data to identify abnormal authentication patterns and potential account compromise indicators.
 
**Key areas covered:** Sign-in log analysis, anomaly detection, security monitoring, log correlation.

## Documentation Standard
 
Every project follows a consistent four-file structure: `README.md` (business problem + at-a-glance summary), `ARCHITECTURE.md` (design decisions and compliance mapping), `WALKTHROUGH.md` (full step-by-step build), and `TROUBLESHOOTING.md` (real errors encountered, root cause, and fix — no illustrative examples).
